# 📊 Customer Churn Prediction System

An end-to-end Machine Learning project for predicting telecom customer churn using XGBoost, SHAP Explainability, and Streamlit Dashboard.

---

# 🚀 Project Overview

Customer churn is one of the biggest business problems in the telecom industry.  
This project predicts customers who are likely to leave the company and provides actionable business retention insights.

The project includes:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Hypothesis Testing
- Feature Engineering
- Machine Learning
- SHAP Explainability
- Streamlit Dashboard
- Business Recommendations

---

# 🎯 Business Objective

Predict high-risk customers and help businesses reduce churn using data-driven retention strategies.
